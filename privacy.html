This Privacy Policy explains how Aydmaxx Shorts Uploader (the "Tool"), a private internal automation tool, handles data. The Tool is used only by the owners of the Aydan Makhmudov | Agro and Xina Kitchen YouTube channels ("the Owners").

1. Data the Tool processes

The Tool accesses YouTube data through YouTube API Services (YouTube Data API v3) for the authorized channels only: the channel identifier, videos that are uploaded through the Tool, custom thumbnails, subtitles (captions) and scheduled publish times. The Tool also stores OAuth credentials (an access/refresh token) locally on the Owner's computer in the macOS Keychain.

2. How data is used

Data is used solely to upload the Owners' own videos to the Owners' own YouTube channels and to manage those videos. The Tool has no external users and does not collect data about any other person.

3. Sharing

No data is sold, rented, shared or transferred to third parties. The Tool transmits data only to Google/YouTube through the official YouTube API Services endpoints.

4. YouTube API Services and Google policies

This Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

5. Data storage and deletion

OAuth credentials and working files are stored locally on the Owners' computer and can be deleted at any time. Access can be revoked, and stored authorization data deleted, at Google Account → Third-party apps & services (myaccount.google.com/connections) or by deleting the stored credentials locally. Revoking access removes the Tool's stored OAuth token and stops all further API access. To request deletion of any related data, contact the email below.

6. Changes

Any changes to this policy will be published on this page with an updated date.
